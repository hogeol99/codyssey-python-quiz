# 🧠 파이썬 기초 퀴즈 게임 (Python Quiz Game)

## 📖 프로젝트 개요
본 프로젝트는 파이썬(Python)을 학습하는 사람들이 콘솔 환경에서 재미있게 퀴즈를 풀며 개념을 복습할 수 있도록 만든 **CLI(Command Line Interface) 기반 퀴즈 게임**입니다. 
객체 지향 프로그래밍(OOP)을 적용하여 `QuizGame` 클래스로 전체 로직을 관리하며, JSON 파일을 활용해 사용자의 최고 점수와 추가한 퀴즈 데이터를 영구적으로 저장합니다.

## 🎯 퀴즈 주제와 선정 이유
* **주제**: 파이썬 기초 문법 및 핵심 개념 (리스트, 딕셔너리, 함수 등)
* **선정 이유**: 파이썬은 프로그래밍 입문자들이 가장 많이 접하는 언어입니다. 학습자들이 눈으로만 코드를 읽는 것을 넘어, 직접 퀴즈를 풀고 오답을 확인하며 **스스로 학습 상태를 점검하고 기초를 탄탄히 다질 수 있도록** 돕기 위해 이 주제를 선정했습니다.

## 🚀 실행 방법
이 프로그램은 Python 3.x 환경에서 동작합니다. 별도의 외부 라이브러리 설치가 필요하지 않습니다.

1. 터미널(또는 명령 프롬프트)을 엽니다.
2. 프로젝트 폴더로 이동합니다.
3. 아래 명령어를 입력하여 게임을 실행합니다.
```bash
   python main.py
```
# ✨ 기능 목록
1. **퀴즈 풀기**: 저장된 퀴즈를 순서대로 풀고 점수를 획득합니다. (정답 시 10점)
2. **퀴즈 추가**: 사용자가 직접 새로운 문제, 4개의 보기, 정답을 입력하여 퀴즈를 추가할 수 있습니다.
3. **퀴즈 목록 보기**: 현재 등록되어 있는 모든 퀴즈의 문제 목록을 확인합니다.
4. **최고 점수 확인**: 역대 플레이 기록 중 가장 높은 점수를 확인합니다. (미참여 시 안내 메시지 출력)
5. **데이터 저장 및 불러오기**: 게임 종료 후 다시 실행해도 추가한 퀴즈와 최고 점수가 유지됩니다.
6. **강력한 예외 처리**:
- 메뉴 및 정답 입력 시 문자나 빈칸 입력 방지
- 데이터 파일(state.json) 손상 시 기본 퀴즈 데이터로 자동 복구

# 💾 데이터 파일 설명 (state.json)
프로그램의 상태를 유지하기 위해 JSON 형식의 파일을 사용합니다.

**경로**: 프로젝트 루트 디렉토리 (./state.json)
**역할**: 사용자가 추가한 커스텀 퀴즈 데이터와 플레이를 통해 갱신된 최고 점수를 저장하여, 프로그램을 껐다 켜도 이전 상태를 그대로 불러옵니다.

**스키마 (데이터 구조)**:
```bash
{
    "best_score": 0,
    "quizzes": [
        {
            "question": "퀴즈 문제 내용",
            "choices": [
                "1. 보기 1",
                "2. 보기 2",
                "3. 보기 3",
                "4. 보기 4"
            ],
            "answer": 1
        }
    ]
}
```
- **best_score (Integer)**: 현재까지 획득한 최고 점수
- **quizzes (Array)**: 퀴즈 객체(question, choices, answer)를 담고 있는 리스트
